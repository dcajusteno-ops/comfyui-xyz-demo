# ComfyUI XYZ Demo

## 📖 项目全局简介
ComfyUI XYZ Demo 是一个深度定制的、功能强大的 ComfyUI 前端 Web 管理面板与高级绘图控制台。
旨在极大提升本地大模型（Stable Diffusion 等）的工作流操作效率，将底层复杂的节点连线封装为直观、现代化的 Web UI。

项目基于 **React 19 + Vite 7** 构建，后端通过专门的 Node.js 跨域代理服务与 ComfyUI 原生 8188 端口 API 进行无缝交互。

## 🎯 已开发的核心功能模块 (Core Features)

目前项目已搭建完毕基础架构，并实现了以下核心标签页功能：

### 1. 默认生图 (Default Generation)
- 标准的文生图/图生图控制面板。
- 支持基础模型（Checkpoint）、采样器（Sampler）、调度器（Scheduler）的快捷切换。

### 2. WD1.4 提示词反推 (WD14 Tagger)
- 深度集成 WD1.4 图像反推逻辑。
- 支持直接上传图片并提取对应的正面和负面 Tag。

### 3. 多人工作流 (Multi-character)
- 强大的多角色蒙版控制机制，可以在同一张图中为多个不同角色分配不同的 Prompt。
- 支持画布区域划分与自动组合。

### 4. 高清修复 (Highres Fix)
- 内置针对生成图像的二次放大与细节重绘功能，支持多种重绘算法与放大倍率参数配置。

### 5. XYZ 控制器 (XYZ Plot)
- 参数矩阵网格生成器。可以一次性对比不同步数、不同 CFG、不同采样器甚至不同 LoRA 权重的出图效果。
- **网格无缝导出**：支持一键将跑完的矩阵图像导出合并为高清网格长图。
- **智能信息打标**：如果使用的是提示词生成模式，导出的网格末尾还会智能追加并标明每个生成的具体提示词后缀。
- **LoRA 批量测试强化 (v0.1.6 新增)**：支持通过“追加 LoRA 模型”和“追加 LoRA 强度”无损测试新模型，并且支持序列语法糖 `{start..end..step}` 自动展开测试阵列。
- **进度常驻提醒与导出重构 (v0.1.9 新增)**：批量运行时顶栏常驻显示批次进度与当前组合参数，标签页标题同步更新；结果图点击可查看大图；导出网格带标题栏与轴标题，长文本自动换行不再截断。
- **(v0.0.2 优化)**：重构了长轴配置界面的 Flex 布局，彻底修复了长列表参数无法正常向下滚动的问题。

### 6. LoRA 管理系统 (Lora Management) - 近期重点优化
- 完善的 LoRA 卡片式展示、分组过滤与检索。
- **智能示例图同步**：
  - **一键拉取（增量同步）**：批量获取封面图和视频，自动跳过本地硬盘中已存在（SHA256匹配）的文件，极致节省带宽。
  - **单独拉取（强制刷新）**：点击单张图片拉取时绕过验证，强制全量下载并覆盖可能损坏的旧文件。
- **文件锁容错机制 (EPERM 免疫)**：彻底解决了 Windows 系统下资源管理器偶尔锁定下载临时文件导致覆盖失败的痛点。

### 7. 专业提示词记事本 (Professional Prompt Notepad) - v0.2.0 深度重构
- **从通用到专业**：彻底摒弃了复杂的富文本与 Markdown 源码干扰，回归纯净的提示词编辑体验。
- **一键复制到 ComfyUI**：新增高亮动作按钮，点击即自动清洗格式（剥离 HTML、合并空行）并写入剪贴板，完美适配生图工作流。
- **智能自动保存**：引入静默防抖保存机制，内容变更 2 秒后自动同步至后端，无需担心数据丢失。
- **全宽专注模式**：支持一键隐藏右侧输出面板，为长篇 Prompt 编写提供双倍视野。
- **快捷提示词片段**：内置常用质量词、风格词及负面提示词的一键插入功能，大幅提升起稿速度。
- **基础工具集成**：保留了字号缩放、时间戳插入、清理残留格式以及 txt 文件导入导出功能。

### 8. 可视化提示词与编辑器 (Prompt Editor) - v0.1.7 极致重构
- **纯正本地 JSON 数据存储**：彻底摒弃浏览器 LocalStorage 依赖。新增 Node.js Vite 后端插件，将用户所有的模板、收藏、历史和自定义词条以 JSON 格式安全固化至项目 `data/prompts_state.json` 文件中，支持 Git 持久化管理。
- **本地文件批量导入**：支持一键上传 `.json`、`.txt`、`.csv` 文件进行词库数据的精准结构化导入，免去手动粘贴的繁琐。
- **级联智能下拉筛选**：彻底重构了来源、分类、子分类的级联检索逻辑。选中“某来源”后，分类下拉框将精准收缩，只展示该来源内真实存在的选项，极大地提升了筛选效率。
- **SDWebUI 风格的提示词方块**：输入框下方会自动将逗号分隔的提示词解析为可视化的胶囊方块。完美兼容包含转义字符与嵌套括号的复杂提示词。
- **极速权重调整**：只需点击方块上的 `+`/`-` 按钮即可快速增减词条权重，或在输入框内使用 `Ctrl+↑/↓`，修改会实时双向同步，彻底告别容易数错括号的痛苦。
- **原生 App 级交互体验**：全局禁用了无效的 UI 文本选中，防止误触高亮，只保留必要的参数文字与输入框的可复制权限。

  - **全量汉化翻译**：将面板内 Trigger Words (触发词)、Version、Size、Base Model 等大量散落的英文标签 100% 翻译为中文。
  - **UI 冗余清理**：剔除了占用面积大但日常使用率极低的“附加备注”与“SHA256 哈希值”等区块，令版面信息更为紧凑清晰。

### 10. 翻译系统底盘重构与词条权重算法修复 (v0.0.5 新增)
- **翻译系统断臂求生**：移除了配置繁琐、鉴权严苛的火山引擎翻译，并将原有的底层翻译模块重构。当前使用内建的反向代理方案完美支持 **阿里云 (Aliyun)** 与 **百度翻译 (Baidu)** 并且彻底跨越 CORS 跨域限制，保障 API 调用安全与稳定。
- **UI 减负优化**：剔除了与提示词胶囊（Visual Tag Blocks）产生操作冲突的全局增减权重按钮，使操作逻辑更统一（全权交由下方的可视化胶囊独立控制）。
- **正则表达式核心修复**：修复了原版正则匹配器 `[0-9.]+` 对负数的不支持漏洞。现在即使通过胶囊按钮将词条权重狂降至 `-0.1` 甚至更低，底层也能完美解析（升级为 `(-?[0-9.]+)`），彻底告别因负号导致的格式串联与权重叠加乱码问题。

### 11. 单个提示词独立翻译与本地词库直读 (v0.0.5.2 新增)
- **单个胶囊独立翻译**：在每个可视化的提示词胶囊内追加了独立的“翻译为中文”按钮，支持不影响整体英文提示词的情况下，实时预览单个词条的中文含义，完美嵌入在对应词条的正下方。

- **布局深度自适应**：解除了之前由于防止页面过长而设定的 `150px` 最大高度限制，同时通过 `whiteSpace: nowrap` 保障了多按钮极限压缩下的文本不换行体验，操作体验全方位提升。

### 12. 简易 LoRA 管理器弹窗与快捷入口 (v0.0.6 新增)

## 🚀 快速开始 (Quick Start)

如果您是首次从 GitHub 拉取或下载本项目的代码，由于庞大的第三方依赖库 (`node_modules`) 已被 Git 忽略，**请务必手动安装依赖**后才能正常启动项目。

1. **克隆项目并进入目录**：
   ```bash
   git clone https://github.com/dcajusteno-ops/comfyui-xyz-demo.git
   cd comfyui-xyz-demo
   ```

2. **安装依赖 (必做)**：
   ```bash
   npm install
   ```

3. **启动开发服务器**：
   ```bash
   npm run dev
   ```
   *(注：在 Windows 环境下也可以直接双击 `run.bat`，它会自动处理端口冲突并自动在浏览器中打开页面)*

## 🧩 核心插件与模型依赖

本项目深度依赖部分 ComfyUI 原生及第三方节点，请确保您的 ComfyUI 环境中已安装以下插件与模型：

### 第三方插件列表 (请在 ComfyUI Manager 中安装)
- **ComfyUI-Impact-Pack**：提供人脸、手部等局部高清修复节点及 SAM 加载器。
- **rgthree-comfy**：提供工作流内部的图像滑块对比节点。
- **ComfyUI-WD14-Tagger**：提供 WD1.4 提示词反推能力。
- **ComfyUI_Mira**：提供 CL Tagger 提示词反推能力与附加组件。
- **ComfyUI-Prompt-Control**：提供 LoRA 懒加载及提示词权重动态调度。
- **ComfyUI-Danbooru-Gallery**：提供 MultiCharacterEditorNode 多角色蒙版生成。
- **ComfyUI-Lora-Manager**：提供原生的 LoRA 检索及元数据管理服务。
- **was-node-suite-comfyui**：提供 Text Concatenate 文本拼接等基础核心节点。
- **ComfyUI_yanc**：提供目录读取及图片/文本批量存取扩展节点。

### 本项目专属自定义节点 (需手动安装)
- **ComfyUI-DrawText-Advanced**
  - **用处**：专为本项目定制的高级文字绘制节点。彻底重写了底层 PIL 图像渲染逻辑，完美支持高质量的**文字旋转**与基于同色描边的**无级字体加粗**。同时它也与前端的 XYZ 控制器无缝打通，支持文字属性的批量矩阵测试。
  - **安装位置**：您需要将本项目根目录下的 `ComfyUI-DrawText-Advanced` 文件夹，完整复制或移动到您的 ComfyUI 安装目录下的 `custom_nodes` 文件夹中（例如 `ComfyUI/custom_nodes/ComfyUI-DrawText-Advanced`），然后重启 ComfyUI 即可生效。

### 核心模型文件下载
请将以下模型放置于 ComfyUI 对应的目录下：
- **脸部修复** (`models/ultralytics/bbox/`)：`face_yolov8m.pt`, `face_yolov8n.pt`, `face_yolov8s.pt`
- **手部修复** (`models/ultralytics/bbox/`)：`hand_yolov8n.pt`, `hand_yolov8s.pt`
- **眼部修复** (`models/ultralytics/bbox/`)：`Eyeful_v2-Individual.pt`
- **NSFW修复** (`models/ultralytics/segm/`)：`ntd11_anime_nsfw_segm_v5.pt`
- **SAM模型** (`models/sams/`)：`sam_vit_b_01ec64.pth`
- **反推模型** (`models/taggers/`)：WD1.4 相关模型 (Moat, ViT, SwinV2, ConvNextV2)
- **CL Tagger** (`models/onnx/cl_tagger/`)：`cl_tagger_1_02.onnx` 及对应的映射 json 文件。

## 🛠️ 运维与启动层优化 (DevOps)

为了彻底解决国内 Windows 环境的疑难杂症，项目拥有一个极度硬核的底层启动机制：
- **终极防闪退脚本 (`run.bat`)**：采用纯粹的 Base64 编码封包 PowerShell 核心代码，利用 `certutil` 和 UTF-8 BOM，彻底免疫任何旧版 CMD 导致的中文乱码与闪退 Bug。
- **幽灵进程收割机制与端口转移 (5173 -> 9999)**：
  - **历史背景**：原默认的 5173 端口在频繁的热更新或异常崩溃时，极易产生残留的 Node 幽灵进程占用端口，导致再次启动时被迫顺延至 5174、5175，极其影响体验。
  - **终极解决**：将项目运行端口硬编码转移至低冲突的 **9999**，并在 `run.bat` 中加入了“端口收割者”逻辑。每次启动/重启前，系统会全网段扫描并无情秒杀任何死锁 9999 端口的进程。
- **自动唤醒浏览器**：在 Vite `npm run dev` 准备就绪后，**自动拉起系统默认浏览器**，直达 `http://127.0.0.1:9999`，实现真正的“一键启动”。
