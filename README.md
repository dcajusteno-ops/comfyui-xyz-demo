# ComfyUI XYZ Demo

## 📖 项目全局简介
ComfyUI XYZ Demo 是一个深度定制的、功能强大的 ComfyUI 前端 Web 管理面板与高级绘图控制台。
旨在极大提升本地大模型（Stable Diffusion 等）的工作流操作效率，将底层复杂的节点连线封装为直观、现代化的 Web UI。

项目基于 **React 19 + Vite 7** 构建，后端通过专门的 Node.js 跨域代理服务与 ComfyUI 原生 8188 端口 API 进行无缝交互。

- 标准的文生图/图生图控制面板。

- 深度集成 WD1.4 图像反推逻辑。

### 3. 多人工作流 (Multi-character)
- 强大的多角色蒙版控制机制，可以在同一张图中为多个不同角色分配不同的 Prompt。

- 内置针对生成图像的二次放大与细节重绘功能，支持多种重绘算法与放大倍率参数配置。

- **智能信息打标**：如果使用的是提示词生成模式，导出的网格末尾还会智能追加并标明每个生成的具体提示词后缀。
- **LoRA 批量测试强化 (v0.1.6 新增)**：支持通过“追加 LoRA 模型”和“追加 LoRA 强度”无损测试新模型，并且支持序列语法糖 `{start..end..step}` 自动展开测试阵列。
- **进度常驻提醒与导出重构 (v0.1.9 新增)**：批量运行时顶栏常驻显示批次进度与当前组合参数，标签页标题同步更新；结果图点击可查看大图；导出网格带标题栏与轴标题，长文本自动换行不再截断。
- **(v0.0.2 优化)**：重构了长轴配置界面的 Flex 布局，彻底修复了长列表参数无法正常向下滚动的问题。

- **三个模板补齐图生图**：默认生图 / 多人工作流 / 高清修复面板顶部新增「图生图」**开关**（默认**关闭**，保证既有行为不变）。开启后可选参考图，链路为 `LoadImage → ImageScale → VAEEncode → KSampler`，重绘强度复用面板既有的「重绘」参数。

- **多人工作流保留分辨率对齐**：缩放节点的宽高接 `ResolutionMasterSimplify` 的输出，不绕过分辨率对齐逻辑。
- **批量语义不丢**：`batchSize > 1` 时插入核心 `RepeatLatentBatch` 复制 latent（上限 64，超出会在面板上给出提示）。
- **两条非阻断提示**：未选参考图时提示「本次将按文生图出图」；重绘强度 > 0.95 时提示「参考图几乎不起作用」——默认值 1 最容易踩这个坑。
- **输出图一键回流**：输出面板每张图新增「作为输入图 ▾」下拉，可直接送往 默认生图 / 多人工作流 / 高清修复 / Anima 生图 / 图片识别（WD1.4）。实现上把 `output/` 的图重新上传为 `input/` 资源（`LoadImage` 只读 `input/`）。
- **两处「只说一半就静默失效」的坑已堵**：送往 Anima 时会一并打开 `stages.img2img`（它的惰性条件是「开关 && 有图」）；送往图片识别时会清掉此前的本地文件（`runWd14` 里 `wdFile` 优先于 `imageName`），并在拖拽区显示「已选：xxx」。
- **预设不携带参考图**：保存参数预设时会剥离 `img2img.imageName`（它指向 `input/` 里的具体文件，换机器后必然失效，回填会被校验拒绝）。
- **枚举隔离**：图生图缩放的采样方法独立拉取 `ImageScale.upscale_method`。**不可复用**「放大方法」那份——后者来自 `LatentUpscaleBy`，含 `bislerp` 而无 `lanczos`，对 `ImageScale` 非法。
- **Anima 零回归**：Anima 的图生图实现与其 `keepProportion` / `cropPosition` 字段语义未变，设置值不丢。

## 🛠️ 运维与启动层优化 (DevOps)

为了彻底解决国内 Windows 环境的疑难杂症，项目拥有一个极度硬核的底层启动机制：
- **终极防闪退脚本 (`run.bat`)**：采用纯粹的 Base64 编码封包 PowerShell 核心代码，利用 `certutil` 和 UTF-8 BOM，彻底免疫任何旧版 CMD 导致的中文乱码与闪退 Bug。
- **幽灵进程收割机制与端口转移 (5173 -> 9999)**：
  - **历史背景**：原默认的 5173 端口在频繁的热更新或异常崩溃时，极易产生残留的 Node 幽灵进程占用端口，导致再次启动时被迫顺延至 5174、5175，极其影响体验。
  - **终极解决**：将项目运行端口硬编码转移至低冲突的 **9999**，并在 `run.bat` 中加入了“端口收割者”逻辑。每次启动/重启前，系统会全网段扫描并无情秒杀任何死锁 9999 端口的进程。
- **自动唤醒浏览器**：在 Vite `npm run dev` 准备就绪后，**自动拉起系统默认浏览器**，直达 `http://127.0.0.1:9999`，实现真正的“一键启动”。
- **局域网一键可达**：启动后自动打印本机与局域网访问地址，并尝试自动放行 9999 端口防火墙规则（无管理员权限时给出可复制的手动命令）；手机访问 `http://<局域网IP>:9999/#/mobile-tag` 即可远程使用 WD1.4 识图。
