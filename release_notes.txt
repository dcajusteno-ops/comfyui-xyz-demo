### 21. XYZ 控制器 LoRA 批量测试强化 (v0.1.6 新增)
- **支持一键追加测试 LoRA 模型**：在 XYZ 控制器中新增了“追加 LoRA 模型”和“追加 LoRA 强度”轴选项，可以无损附加在当前模板的基础模型之上，完美解决炼丹后需要批量测试多个 Epoch 模型但不想覆盖原有底模环境的痛点。
- **自动序列扩展语法糖 `{start..end..step}`**：支持在 LoRA 名称输入框中使用类似 `SDXL\cs\kuroida_v0.1-{000006..000012..2}.safetensors` 的语法，系统将智能根据步长（Step）和补零规则自动展开为多个独立的 LoRA 模型组合，极大简化了序列模型的测试流程。
- **修复了现有模型名显示与阵列覆盖问题**：修复了替换已有 LoRA 时显示名称丢失的问题，并重构了内部阵列配置合并逻辑，支持一次测试多个 LoRA 维度而互不干扰。

### 20. 交互细节重构与多角色控制进阶 (v0.1.5 新增)
- **多角色标签页联动重构**：将冗长的多人工作流堆叠卡片重构为带状态圆点的顶部联动标签页 (Tabs)。并且与左侧画布蒙版实现了双向绑定：在画布中点选任何区域，右侧编辑器均会无缝丝滑地切换至对应角色，彻底告别来回滚动的繁琐操作。
- **超紧凑坐标栏控制**：将底层坐标、尺寸 (x,y,w,h) 以及遮罩羽化参数压缩整合，释放了极其宝贵的屏幕纵向空间。
- **管理器侧边栏记忆滚动**：大幅优化了 LoRA 管理器的文件夹树交互体验。现在关闭管理器后再重新打开，侧边栏会自动将上次选中的文件夹滚动居中至可视区域，保持视觉与操作的连贯性。

### 19. 极致 UI 体验打磨与 LoRA 兼容性修复 (v0.1.4 新增)
- **LoRA 跨平台路径解析修复**：彻底修复了在 Windows 平台下，由于 ComfyUI 底层路径返回反斜杠而导致的 PCLazyLoraLoader (PromptControl 懒加载) 无法匹配文件并报 not found 的致命错误，确保多人工作流中各自的 LoRA 完美生效。
- **简易 LoRA 管理器状态穿透修复**：修复了在简易管理器中点击进入详情页会销毁底层弹窗状态的问题，现已完美支持从详情页退回至列表，实现了沉浸式的选模型体验。
- **组件层级与排版优化**：修正了 LoRA 详情弹窗的 z-index 渲染顺序，使其能正确盖住简易管理器；并将多人工作流面板内的新增角色按钮剥离，统一下沉至底部核心操作栏，配合 CSS 局部滚动彻底杜绝了高频操作按钮随列表滚走的体验痛点。
